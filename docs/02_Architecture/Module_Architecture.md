# Архитектура модулей DevHub

Версия документа: 0.1

---

# 1. Общая архитектура

DevHub строится по модульному принципу.

Каждый функциональный блок является независимым модулем.

Модули взаимодействуют через внутренние интерфейсы.

Это позволяет:

- независимо развивать функциональность;
- подключать новые возможности без изменения ядра;
- тестировать каждый модуль отдельно.

# 3. Назначение модулей

## Core

Ядро приложения.

Отвечает за:

- запуск приложения;
- загрузку конфигурации;
- регистрацию модулей;
- маршрутизацию событий.

---

## Workspace

Управление рабочими каталогами.

Функции:

- поиск репозиториев;
- мониторинг структуры;
- индексирование проектов.

---

## Git

Работа с локальным Git.

Функции:

- Fetch
- Pull
- Push
- Commit
- Branch
- Merge
- Tag

---

## GitHub

Работа через GitHub API.

Функции:

- репозитории;
- Issues;
- Pull Requests;
- Releases;
- Actions.

---

## UI

Интерфейс пользователя.

Функции:

- главное окно;
- карточки проектов;
- журнал операций;
- настройки.

---

## AI

Интеллектуальный помощник.

Будущие функции:

- анализ структуры проекта;
- рекомендации;
- генерация Commit Message;
- генерация документации;
- анализ ошибок.

---

## Plugins

Подключаемые расширения.

Каждый плагин является независимым модулем.

---

## Settings

Настройки приложения.

Использует JSON-конфигурацию.

---

## Logging

Журналирование.

Функции:

- логирование действий;
- журнал ошибок;
- история синхронизации.

# 5. Принципы разработки

Каждый модуль:

- имеет собственную ответственность;
- не зависит напрямую от других модулей;
- тестируется отдельно;
- документируется отдельно.
