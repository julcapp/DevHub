# DevHub — голосовые заметки (Windows 10/11 x64)

## Принятая архитектура

- Встроенное локальное распознавание речи — основной режим DevHub.
- Handy — обязательная внешняя интеграция в составе поддерживаемой установки; отказ Handy не блокирует работу DevHub.
- Поддерживаемые платформы: Windows 10 x64 и Windows 11 x64.
- Мультиязычная модель Whisper с русским языком может поставляться внутри установщика; после установки распознавание не должно требовать сети.
- Не отправлять записи на внешние сервисы без отдельного согласия пользователя.

## Сборка и установка

Текущий `build.bat` — настройка среды разработчика, **не** переносимый установщик. Нельзя считать проект готовым к переносу без Python до появления отдельной сборки и проверок.

План релиза:
1. Отдельный сервис записи аудио и распознавания в рабочем потоке, с явными разрешениями микрофона, отменой и сообщениями об ошибках.
2. Подключение локального Whisper backend; фиксация версии и контрольных сумм модели и библиотек.
3. Сборка Windows x64 с включёнными библиотеками, моделью и официальным установщиком Handy (при соблюдении лицензий и условий распространения).
4. Проверка установки Handy и его CLI/горячих клавиш; возможность восстановить интеграцию.
5. Чистая установка на Windows 10 и 11 x64, проверка работы без интернета, микрофона, сохранения заметок и удаления временных WAV-файлов.
6. Подписание установщика и проверка предупреждений Windows Defender/SmartScreen.

## Критерии приёмки

- Не нужен предварительно установленный Python, pip или доступ в интернет.
- Работает русская речь на CPU без GPU; ускорение GPU — опционально.
- Handy устанавливается или подключается через официальный дистрибутив и проверяется при настройке.
- При отсутствии Handy встроенное распознавание доступно, а диагностика указывает на проблему.
- Сохраняются документы после переключения раздела, закрытия окна и перезапуска.
- Выполнены Windows 10/11 x64 smoke tests на чистых машинах.
