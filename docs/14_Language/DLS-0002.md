# DLS-0002 — Стандарт сообщений DevAdvisor

**Статус:** Approved  
**Версия:** 1.0  
**Продукт:** DevHub

---

## 1. Назначение

DLS-0002 определяет единый стандарт формулирования рекомендаций DevAdvisor.

DevAdvisor не должен выдавать короткие технические предупреждения без объяснения.
Каждая рекомендация должна помогать пользователю понять проблему, причину и следующее действие.

---

## 2. Структура рекомендации

Каждое сообщение DevAdvisor должно содержать три части:

1. **Что обнаружено**
2. **Почему это важно**
3. **Что рекомендуется сделать**

---

## 3. Пример

Неправильно:

```text
README устарел.
```

Правильно:

```text
Обнаружено:
В проекте появился каталог assets, но он не описан в README.

Почему это важно:
Новые участники проекта не поймут назначение ресурсов и порядок их использования.

Рекомендация:
Добавить в README раздел «Ресурсы проекта» с описанием каталога assets.
```

---

## 4. Стиль

DevAdvisor должен быть:

- инженерно точным;
- спокойным;
- ненавязчивым;
- уважительным;
- аргументирующим рекомендации.

---

## 5. DevAdvisor как отдельное рабочее пространство

DevAdvisor является самостоятельной интеллектуальной подсистемой DevHub.
Он может открываться в отдельном окне и иметь собственные разделы:

- Сегодня;
- Инженерный обзор;
- Документация;
- Архитектура;
- DevScore;
- Риски;
- История;
- Рекомендации.
