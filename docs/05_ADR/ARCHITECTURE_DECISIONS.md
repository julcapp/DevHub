# DevHub Architecture Decision Record (ADR)

Статус: Active

Этот документ фиксирует ключевые архитектурные решения проекта DevHub.

------------------------------------------------------------------------

## ADR-001 --- Workspace

**Статус:** Accepted

**Решение**

Использовать единое рабочее пространство:

`C:\Users\iav\Documents\GitHub\DevHub-Workspace`

**Причина**

Единая точка входа для всех репозиториев проекта, предсказуемое
сканирование и упрощение переноса среды разработки.

------------------------------------------------------------------------

## ADR-002 --- StatusService

**Статус:** Accepted

**Решение**

Вся информация о состоянии приложения проходит через `StatusService`.

**Причина**

Отделение бизнес-логики от пользовательского интерфейса.

------------------------------------------------------------------------

## ADR-003 --- GitHubProvider

**Статус:** Accepted

**Решение**

Получение данных GitHub выполняется через Provider, а не напрямую из UI.

**Причина**

Изоляция внешних источников данных и возможность дальнейшего расширения.

------------------------------------------------------------------------

## ADR-004 --- Workspace Scan Rules

**Статус:** Accepted

**Решение**

Сканируются только рабочие репозитории верхнего уровня Workspace.

Каталоги `Archive` и `Temp` исключаются.

------------------------------------------------------------------------

## ADR-005 --- EDP Packages

**Статус:** Accepted

**Решение**

Все изменения поставляются пакетами EDP с инструкциями, тестами,
журналом изменений и возможностью отката.

------------------------------------------------------------------------

## ADR-006 --- Release Process

**Статус:** Accepted

Каждый EDP считается завершённым только после:

1.  Установки.
2.  Smoke Test.
3.  Commit и Push в DevHub.
4.  Commit и Push в DevHub-Platform.
