# Требования: Research & Evolution Center v1

## Цель

Превратить GitHub Stars пользователя в управляемую инженерную библиотеку, где внешний репозиторий проходит путь от обнаружения и анализа до исследования и создания собственной разработки.

## Функциональные требования

### RE-01. Синхронизация GitHub Stars

Система получает список starred repositories подключённого GitHub-пользователя и сохраняет GitHub ID, URL, владельца, название и дату синхронизации.

### RE-02. Карточка звёздочки

Карточка показывает метаданные, README-аннотацию, стек, лицензию, активность, статистику, заметки, связанные идеи, исследования и проекты.

### RE-03. AI-анализ

Система формирует назначение проекта, сильные и слабые стороны, зрелость, риски, коммерческий потенциал, варианты применения и рекомендуемое действие.

### RE-04. Research Workspace

Пользователь создаёт исследование на основе Star, фиксирует цель, вопросы, материалы, вывод, решение и дальнейшее действие.

### RE-05. Начать собственную разработку

После анализа система предлагает сценарии:

- создать Fork;
- клонировать локально;
- создать Fork и рабочую ветку;
- создать производный проект с паспортом DevHub;
- создать независимый репозиторий, когда это допускается лицензией;
- использовать проект как библиотеку или образец архитектуры.

### RE-06. Проверка происхождения и лицензии

Перед созданием производного проекта система показывает лицензию, предупреждения и обязательные условия сохранения авторства.

### RE-07. Evolution Tree

DevHub сохраняет цепочку: исходный репозиторий → Star → исследование → решение → Fork/Clone → производный проект → последующие версии.

### RE-08. Явное подтверждение

Операции GitHub/Git, меняющие внешнее или локальное состояние, выполняются только после явного подтверждения пользователя.

## Нефункциональные требования

- интерфейс по умолчанию на русском языке;
- GitHub ID используется для защиты от дублей;
- повторная синхронизация не уничтожает пользовательские заметки и решения;
- AI-выводы имеют дату, версию модели/алгоритма и могут быть пересмотрены;
- связи между объектами доступны через API;
- модуль не зависит от Lk_uni и не включает его компоненты.

## Критерий готовности первой версии

Пользователь видит синхронизированный каталог Stars, открывает карточку, запускает анализ, создаёт Research и может инициировать мастер производного проекта без автоматического выполнения необратимых действий.
